# Angelo Bronosa — Personal Portfolio

A responsive, dark minimalist portfolio made with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — semantic page structure and content
- `style.css` — layout, colors, responsive breakpoints, and reduced-motion support
- `script.js` — mobile menu, theme toggle, active navigation, current year, and demo contact form
- `assets/angelo.jpg` — profile photo used in the hero section

## Run locally
1. Keep all three files in the same folder.
2. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.
3. Edit the placeholder text in `index.html` to add your school name, dates, achievements, and accurate project links.
4. In `script.js`, replace `ADD_YOUR_EMAIL@example.com` with an email address you want visitors to use. The form opens the visitor's email app; it does not store or send messages through a server.
5. Your uploaded profile photo is already included at `assets/angelo.jpg`. To change it later, replace that file while keeping the same filename, or update the image path and alt text in `index.html`.

## Publish with GitHub Pages
1. Sign in to GitHub and open `https://github.com/angelobronosa1742`.
2. Create a new public repository named `angelo-portfolio` (or another name you prefer).
3. Upload `index.html`, `style.css`, and `script.js` to the repository's root folder. You can use **Add file → Upload files**.
4. Commit the files.
5. Open the repository's **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Choose branch **main** and folder **/(root)**, then save.
8. Wait a few minutes. GitHub will display the published website URL in the Pages section. It will usually look like `https://angelobronosa1742.github.io/angelo-portfolio/`.
9. Open the published URL and test the menu, theme toggle, project links, and layout on a phone.
